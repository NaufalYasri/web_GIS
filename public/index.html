Cara Melakukan Digitasi

  1. Gunakan toolbar di sisi kiri peta.
  2. Pilih ikon Titik , Garis , atau Poligon .
  3. Klik di peta untuk menggambar (klik ganda / klik titik awal untuk mengakhiri garis/poligon).
  4. Formulir penyimpanan akan muncul otomatis. Isi nama, kategori, dan klik Simpan!
  5. Data langsung tersimpan di PostGIS dan dapat langsung dilihat di QGIS!

Cara Menyambungkan ke QGIS Desktop

Semua objek yang kamu digitasi di web ini langsung tersimpan ke database PostGIS. Ikuti langkah mudah berikut untuk membukanya di QGIS:

1

Buka QGIS & Tambah Koneksi PostGIS

Di panel sebelah kiri QGIS (Browser Panel), cari item PostGIS, lalu klik kanan → pilih New Connection...

2

Isi Parameter Koneksi PostGIS

Name: WebGIS Digitasi
Host: localhost
Port: 5432
Database: webgis_digitasi
Authentication: Basic (User: postgres, Password: [password anda])

Klik Test Connection. Jika muncul centang hijau "Connection was successful", klik OK.

3

Tampilkan Layer ke Kanvas Peta QGIS

Buka folder webgis_digitasi → public. Anda akan melihat 3 layer:
• digitasi_titik
• digitasi_garis
• digitasi_poligon
Cukup klik ganda atau drag & drop layer tersebut ke Layers Panel QGIS!

4

Tips Real-time Auto Refresh di QGIS!

Agar saat kamu menggambar di web, QGIS otomatis mengupdate petanya tanpa perlu klik reload manual:
1. Klik kanan pada layer di QGIS → Properties → tab Rendering.
2. Centang "Refresh layer at interval (seconds)" dan masukkan 2 detik.
3. Sekarang QGIS kamu otomatis sinkron secara langsung dengan Web Digitasi!
